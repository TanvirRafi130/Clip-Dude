# Security

ClipDude is designed to run on the local computer and binds to `127.0.0.1` by default. Do not expose the service to an untrusted network.

## Reporting a vulnerability

Report suspected vulnerabilities privately to the project owner through the repository's private security reporting channel. Include a concise description, reproduction steps, and potential impact. Do not publish credentials, private videos, or other sensitive data in a public report.

## Security expectations

- Keep `.profile` and API credentials private.
- Do not expose the local server to the public internet.
- Review video URLs and files before processing.
- Keep Python packages, FFmpeg, and Ollama updated.
